# Music Assets

Place locally licensed `.mp3` or `.wav` tracks here using the names in
`playlist.json`. MP3 files are intentionally ignored by Git so personal music
is never published with the source code. The player supports Windows directly;
on Raspberry Pi it uses the first available player among `mpg123`, `ffplay`,
or VLC (`aplay` remains available for WAV files).

The five supported categories are `calm`, `warm`, `happy`, `energetic`, and
`celebration`. Keep permission or license information for every track used in a
public demonstration.
